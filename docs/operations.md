# Operations and troubleshooting / 运维与故障排查

## Backup / 备份

The safest file-level backup stops the application so the SQLite database and its WAL files are consistent:

```bash
docker compose stop awsl-remotex
tar -C data -czf "awsl-remotex-data-$(date +%Y%m%d-%H%M%S).tar.gz" .
docker compose start awsl-remotex
```

Back up `.env` separately in a secret manager. Never commit it. The database backup is insufficient without the original `CREDENTIAL_KEY` when saved credentials exist.

最安全的文件级备份方式是先停止应用，再备份整个 `data` 目录。`.env` 应单独保存在密钥管理系统中；存在已保存凭据时，没有原始 `CREDENTIAL_KEY` 就无法恢复。

## Restore / 恢复

1. Stop `awsl-remotex`.
2. Restore the archive into an empty `data` directory.
3. Restore the same `CREDENTIAL_KEY`. `GUACAMOLE_JSON_SECRET` may be rotated, but the application and Guacamole must use the same current value.
4. Start the service and check `/api/ready` before using assets.

Do not merge files from different SQLite backups or copy only the `.db` file while the service is running.

## Timeout behavior / 超时行为

- `SESSION_IDLE_TIMEOUT` belongs to Awsl RemoteX. Browser activity updates each tab's timestamp; an inactive tab is disconnected after this duration.
- `GUACAMOLE_SESSION_TIMEOUT_MINUTES` is passed to Guacamole as `API_SESSION_TIMEOUT` by Compose.
- Connection tickets generated by Awsl RemoteX are valid for 30 seconds and are exchanged immediately by the frontend.
- The login cookie has a browser lifetime of seven days. Changing `AUTH_USERNAME` or `AUTH_PASSWORD` invalidates its value.

## Logs / 日志

```bash
docker compose logs -f awsl-remotex guacamole guacd
```

Awsl RemoteX writes structured JSON logs to standard output. Failed HTTP requests include method and path but do not intentionally log saved credential values.

## Troubleshooting / 故障排查

| Symptom / 现象 | Checks / 检查 |
| --- | --- |
| `/api/ready` reports database unavailable | Verify the `/app/data` mount is writable and only one replica uses it. / 检查数据卷权限和单副本约束。 |
| `/api/ready` reports `guacd` unavailable | Check `GUACD_ADDRESS`, container DNS, and `guacd` logs. / 检查地址、容器 DNS 与日志。 |
| `/api/ready` reports Guacamole unavailable | Check `GUACAMOLE_UPSTREAM`, Guacamole startup, and JSON extension configuration. / 检查上游地址、启动状态和 JSON 扩展。 |
| Saving a password or key fails | Set a valid 64-character hexadecimal `CREDENTIAL_KEY`. / 设置有效的 64 字符十六进制密钥。 |
| Existing saved credentials no longer work | Restore the exact original `CREDENTIAL_KEY`; encrypted values cannot be reset in place. / 恢复原始密钥，已有密文无法原地解密或重置。 |
| Authentication fails after proxying HTTPS | Preserve `X-Forwarded-Proto: https`, allow cookies, and avoid cross-site embedding. / 保留 HTTPS 转发头并允许 Cookie。 |
| Canvas connects but keyboard input does not arrive | Confirm the tab is active and reconnect after upgrading from an older cached PWA. Reserved browser shortcuts cannot be forwarded. / 确认活动 Tab，清理旧 PWA 缓存或重连；浏览器保留快捷键无法转发。 |
| Two pointers appear | Verify the UI version is at least `v0.2.14` and reload the PWA. / 确认版本不低于 `v0.2.14` 并刷新 PWA。 |
| UI still shows an old version | Close all installed-PWA windows, reopen online, or remove and reinstall the PWA. / 关闭全部 PWA 窗口后联网重开，必要时重新安装。 |

Connection testing first probes the target TCP port and then asks `guacd` to establish the protocol. It does not validate the browser WebSocket or Canvas path; use both `/api/ready` and a real session when diagnosing end-to-end failures.
